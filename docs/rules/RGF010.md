# RGF010 — Service type registered by two implementations

**Severity:** warning · **Category:** Zero.Registration

Two classes register under the same service type. The container keeps both registrations and
returns the last one, so which implementation you get depends on registration order.

This is a warning rather than an error because it is occasionally intended.

## When it is intended

You want all of them, and you resolve the collection:

```csharp
public sealed class ExportService(IEnumerable<IExportFormat> formats);
```

Nothing needs to change — but consider making the intent visible at the registration site.

## When it is not

You wanted one. Separate them with a key and resolve by key:

```csharp
[ServiceTypes("csv", typeof(IExportFormat))]
public sealed class CsvExportFormat : IExportFormat, ITransient;

[ServiceTypes("xlsx", typeof(IExportFormat))]
public sealed class ExcelExportFormat : IExportFormat, ITransient;
```

```csharp
public sealed class ExportService([FromKeyedServices("csv")] IExportFormat format);
```

Or narrow one of them to a different service type, so the two no longer collide.
